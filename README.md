- 入力内容をプラグイン専用JSONとして保存
- 見解、入力、計算、リスク、製品候補、予備試験、参照文献メタデータをPDFで保存
- 外部AI、外部API、外部への実験情報送信は未実装。現在は閉域のルールベース試作
- 圧力、流量、界面活性剤濃度など、製品マニュアルまたは社内検証データにない具体的条件は生成しない

### 有料プラグインの分離設計

- `plugins/experiment_condition_advisor/` に入力画面、計算、見解エンジン、承認済み文献メタデータ、PDF処理を隔離
- コア側は `core/feature_registry.py` とプラグインIDだけを持ち、プラグインを直接importしない

- プラグイン専用データは既存の進行データへ混在させず、`plugin_data_schema_version=1` で管理
- PDF用のReportLabは `optional_requirements/experiment_condition_advisor.txt` へ分離

## 起動方法

```bash
pip install -r requirements.txt
pip install -r optional_requirements/experiment_condition_advisor.txt
streamlit run app.py
```

有料プラグインを含まない配布物では、2行目は不要です。`launch.bat` は専用optional requirementsが存在する場合だけ追加インストールします。

Windowsでは `launch.bat` からも起動できます。
