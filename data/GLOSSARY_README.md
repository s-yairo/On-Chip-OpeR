# 用語集データ

`glossary.json` は、実験ナビ、測定結果、トラブル案内、実験条件検討に表示される専門語を、専門教育を受けていない文系学生または普通高校3年生向けに説明するデータです。

## 収録方針

- 用語名、略語、英語画面名、単位、ファイル形式、蛍光色素名を対象とする
- 説明文は、別の専門語を知らなくても概要を理解できる表現にする
- 説明文中に不可欠な専門語は、その専門語も別項目として収録する
- `product_catalog.json` に掲載された製品名、製品番号、製品固有仕様は収録しない
- 製品情報は「製品一覧」を単一の参照元とする

## データ項目

- `term`: 画面へ表示する用語名
- `aliases`: 略語、英語名、別表記などの検索語
- `category`: 分野
- `description`: 初学者向けの説明

## 更新時の確認

1. `manual_steps.json` の工程本文・用語解説・トラブル案内を照合する
2. `app.py` の結果解説、共通画面、用語集以外のユーザー向け文言を照合する
3. 実験条件検討の入力項目と結果表示を照合する
4. 新しい専門語が用語または別名から検索できることを確認する
5. 製品カタログの製品名が用語集へ混入していないことを確認する
