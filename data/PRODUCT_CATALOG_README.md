# product_catalog.json

`New_製品価格表【20260801】_20260611ver3.xlsx` の3シートを基に、製品一覧ページ用として生成したデータです。

- 対象：装置33件、オプション19件、試薬・消耗品19件、合計71件
- 価格項目：収録しない
- 元Excel：アプリZIPへ同梱しない
- 表示順：元Excelの大分類・カテゴリー・行順を維持
- 空欄項目：JSONへ追加せず、画面でも表示しない
- 製品番号：先頭ゼロや英字を保持できる文字列として保存
- 注記：元Excelに記載された販売終了予定および適応製品略称を保持

価格を画面上で隠すのではなく、`product_catalog.json` 自体に価格フィールドと価格値を入れない方針です。

## v26-no86以降の除外
